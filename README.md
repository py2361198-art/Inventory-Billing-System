# Inventory & Billing System

A full-stack inventory and billing management system built with HTML, CSS, JavaScript, Node.js, Express.js and MySQL.

## Features

- Product management
- Add and delete products
- Stock tracking
- Inventory value calculation
- Product search
- REST API
- MySQL database
- Responsive interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL

## Run locally

1. Install Node.js and MySQL.
2. Create the database by running `database/schema.sql`.
3. Install dependencies:

```bash
npm install
```

4. Start the server:

```bash
npm start
```

5. Open `http://localhost:3000`.
